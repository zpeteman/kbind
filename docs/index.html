nlsh

Natural Language Shell Command Generator

Type what you want to do in plain English, hit Ctrl+G, and watch your terminal instantly write the exact shell command for you.

View on GitHub Install Now
~ ❯ find all giant videos in my downloads folder # Press Ctrl+G...

~ ❯ undo my last git commit but keep the files # Press Ctrl+G...
~ ❯ git reset --soft HEAD~1

Installation

macOS & Linux

Install via our automated script:

curl --proto '=https' --tlsv1.2 -LsSf https://github.com/zpeteman/nlsh/releases/latest/download/nlsh-installer.sh | sh

Windows

Install via PowerShell:

irm https://github.com/zpeteman/nlsh/releases/latest/download/nlsh-installer.ps1 | iex

Debian / Ubuntu

Download the .deb from GitHub Releases:

wget https://github.com/zpeteman/nlsh/releases/latest/download/nlsh.deb
sudo dpkg -i nlsh.deb

Cargo (Rust)

Build from source using Cargo:

cargo install --git https://github.com/zpeteman/nlsh

Quick Setup

  1. Install your shell hook:
    nlsh install-shell zsh
  2. Add your API key: (Supports Anthropic, OpenAI, OpenRouter, Gemini, or local Ollama)
    nlsh config set-key openrouter
  3. Restart your terminal and start typing!
